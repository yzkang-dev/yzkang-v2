## 1. 快速入门

### 1.1 登录

1. 打开浏览器访问管理后台地址（默认 `http://localhost:5174`）

## 2. 功能页面说明

### 2.1 院长看板

**用途**：每日运营数据总览，帮助管理者快速掌握机构动态。

| 数据指标 | 说明 |
|----------|------|
| 在住老人 | 当前入住人数 |
| 今日照护 | 当日照护记录数量 |
| 待处理告警 | 未处理告警数，红色数字需警觉 |
| 今日用药 | 当日用药记录数量 |
| 本月账单 | 当月账单总额 |

### 2.2 老人管理

**用途**：管理所有入住老人的信息档案。

**功能操作**：
- **新增老人**：点击"新增老人"按钮，填写姓名/性别/出生日期/身份证号/联系电话/入住日期等信息
- **查看详情**：点击表格行进入详情页，查看完整档案
- **编辑信息**：在详情页点击"编辑"
- **搜索**：按姓名/身份证号搜索
- **列表筛选**：按状态、楼层等筛选

> 📌 身份证号、联系电话等敏感信息已加密存储，仅授权人员可见。

### 2.3 照护记录

**用途**：记录老人日常照护情况，确保服务质量可追溯。

**操作步骤**：
1. 在表格上方选择老人
2. 点击"添加照护记录"
3. 填写记录时间和照护内容
4. 点击"保存"

**常见记录类型**：饮食情况、睡眠质量、体征监测、活动情况、家属探视

### 2.4 账单管理

**用途**：管理老人费用账单，包括月费、护理费、杂费等。

| 功能 | 说明 |
|------|------|
| 查看账单 | 按老人/状态/时间筛选 |
| 创建账单 | 选择老人→填写金额和费用类型→设定截止日期 |
| 标记已缴 | 确认老人或家属完成缴费 |
| 账单统计 | 按月查看收入统计图表 |

### 2.5 用药记录

**用途**：记录老人用药情况，确保按时按量服药。

**操作步骤**：
1. 选择老人
2. 点击"添加用药记录"
3. 填写药品名称、剂量、服用时间
4. 保存

### 2.6 班次管理

**用途**：管理护理人员的排班情况。

**操作**：
- 查看当前排班表
- 添加班次记录（早班/午班/晚班）
- 签入/签出

### 2.7 生命体征

**用途**：记录老人的生命体征测量数据（血压、心率、体温等）。

**查看方式**：选择老人→查看历史数据表格

> 📊 体征异常会自动触发告警通知。

### 2.8 告警中心

**用途**：集中管理所有告警信息，确保及时响应。

**告警类型**：
- 🔴 紧急：生命体征异常、跌倒检测
- 🟡 警告：异常离床、用药遗漏
- 🔵 普通：定期提醒、系统通知

**处理流程**：
1. 查看告警详情
2. 记录处理措施（备注）
3. 标记为"已处理"

**批量操作**：
- 勾选多条告警 → 批量标记已读
- 勾选多条告警 → 批量处理

### 2.9 报表中心

**用途**：生成运营报表，支持导出 Excel。

**报表类型**：
- 老人入住统计
- 护理质量报表
- 财务收支报表
- 告警统计报表

### 2.10 审批管理

**用途**：处理各类审批请求。

| 审批类型 | 说明 |
|----------|------|
| 请假审批 | 老人临时外出请假 |
| 费用审批 | 特殊费用报销 |
| 其他审批 | 自定义审批流程 |

### 2.11 合同付款

**用途**：管理与养老机构的合同款项支付记录。

### 2.12 视频监控

**用途**：查看公共区域监控画面，确保安全。

## 3. 常见操作

### 3.1 新增老人入住

```
第1步：进入「老人管理」→ 点击「新增老人」
第2步：填写基本信息（姓名、性别、出生日期必填）
第3步：填写联系信息（身份证号、联系电话、紧急联系人）
第4步：设定入住日期
第5步：点击「保存」
第6步：系统自动创建入住照护记录
```

### 3.2 处理告警

```
第1步：看到红色告警提示 → 进入「告警中心」
第2步：点击告警行查看详情
第3步：到现场确认情况
第4步：填写处理措施和备注
第5步：点击「标记为已处理」
```

### 3.3 查看老人完整档案

```
进入「老人管理」→ 点击老人姓名/行 → 进入详情页
可查看：基本信息、照护历史、用药记录、体征趋势、账单状态
```

### 3.4 导出数据

```
大部分列表页右上角有「导出」按钮
点击后下载 Excel (.xlsx) 文件
支持的数据：老人列表、照护记录、账单、用药记录、体征数据
```

### 3.5 修改密码

```
第1步：点击左下角个人用户信息区域
第2步：进入用户管理 → 找到自己的账号
第3步：点击修改密码
第4步：输入新密码并保存
```

## 4. FAQ 常见问题

### Q: 页面加载很慢怎么办？
A: 尝试刷新浏览器（F5 或 Ctrl+Shift+R）。如果持续慢，检查网络连接。

### Q: 出现"Backend unreachable"错误？
A: 后端服务未启动。联系技术人员或重启后端服务。

### Q: 出现"请求过于频繁"提示？
A: 短时间内发送了太多请求。稍等几秒后刷新页面即可。

### Q: 数据没有及时更新？
A: 点击页面刷新按钮，或切换到其他页面再切回来。

### Q: 如何添加新用户？
A: 进入「系统设置」→「用户管理」→「新增用户」，设定角色和权限。

### Q: 忘记密码怎么办？
A: 联系管理员重置密码。管理员可在「用户管理」中为任何用户重置密码。

### Q: 数据会自动保存吗？
A: 表单数据不会自动保存。填写完毕后务必点击「保存」按钮。

### Q: 支持批量导入老人数据吗？
A: 目前支持导出 Excel。批量导入功能将在后续版本中提供。

## 5. 管理员专属

### 5.1 用户管理

**路径**：系统设置 → 用户管理

管理员可以：
- 创建新用户（设定用户名/密码/角色）
- 编辑用户信息
- 修改用户密码
- 删除用户

### 5.2 角色管理

**路径**：系统设置 → 角色管理

管理员可以：
- 创建/编辑/删除角色
- 为角色配置权限
- 将用户分配给角色

**预设角色**：
| 角色 | 权限范围 |
|------|----------|
| 超级管理员 | 全部功能 + 系统设置 |
| 管理员 | 全部功能（无系统设置） |
| 护士 | 照护记录 + 用药 + 体征 |
| 前台 | 老人管理（查看 + 新增） |

### 5.3 审计日志

**路径**：系统设置 → 审计日志

查看所有操作记录，包括：
- 谁在什么时间做了什么操作
- 操作对象
- 操作详情

### 5.4 通知配置

**路径**：系统设置 → 通知设置

配置告警通知方式：
- 短信通知（需配置腾讯云 SMS）
- 邮件通知（需配置 SMTP）
- 系统内通知

### 5.5 数据备份

管理员应定期备份数据库：

```bash
# 手动备份
./scripts/backup.sh backup

# 查看备份历史
./scripts/backup.sh list

# 恢复备份
./scripts/backup.sh restore backups/yzkang_20260611_030000.dump
```

> 📌 建议设置每日自动备份（已配置定时任务则无需手动操作）
